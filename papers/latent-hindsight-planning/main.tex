\section{Definition of latent hindsight planning}
\label{sec:def}
\todo{BLOCKING: replace with the collaborators' definition.}
Working definition used by the current code (\texttt{wmi/train.py:train\_temporal\_distance}):
given trajectories $(o_0,a_0,\dots,o_T)$ and a frozen encoder $z=f(o)$, relabel goals in hindsight as
$g = z_{t+k}$ for $k\sim\mathcal{U}\{0,\dots,K\}$ and fit $d_\theta(z_t,g)$ to $k$ with an expectile loss
($\tau=0.1$) so that $d_\theta$ tracks the lower envelope of random-walk offsets. Planning is CEM-MPC
in latent space with cost $\min_t d_\theta(\hat z_t, z_g)$.
