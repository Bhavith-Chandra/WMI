# WMI — World Model Interpretability

Shared toolkit behind three papers:

| Paper | Directory | Uses |
|---|---|---|
| Latent Hindsight Planning | `papers/latent-hindsight-planning/` | `wmi.planning`, `wmi.train.train_temporal_distance` |
| WMI Tutorial & Methodology | `papers/wmi-tutorial/` | `wmi.probing`, `wmi.interventions`, testbed |
| Open Problems in WM & Interpretability | `papers/open-problems/` | evidence from both of the above |

## Ground rules (enforced in code, not by convention)

1. **No hand-typed numbers.** Results are written only by `wmi.harness.save_result` (git commit, dirty flag, config hash, versions, timestamp). Papers `\input` tables generated by `scripts/make_tables.py` from `results/`.
2. **No leakage.** Splits are by episode and checked by `wmi.harness.check_split` (raises `LeakageError`). Hyper-parameters and early stopping use val only. Planning evaluation uses fresh start/goal pairs from an independent RNG.
3. **No probe without controls.** `wmi.probing.probe_with_controls` always returns real / shuffled-label / Hewitt–Liang control task / majority, plus selectivity; experiment scripts add raw-input and untrained-model baselines. CIs are cluster-bootstrapped over episodes.
4. **No causal claim without a matched control.** Interventions are compared to random edits of equal norm, with a specificity metric.
5. **Determinism.** `wmi.harness.set_seed` seeds everything and forces deterministic torch kernels; a test checks bitwise-identical training.

## Testbed: KeyGrid

7×7 grid, wall at x=3 with a gap at y=3, key at (5,1). Ground-truth state `(x, y, has_key)`.
POMDP stream: full view at t=0, then only a 3×3 egocentric view, so position and key status at t>0 must be carried in memory.

## Run

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install --index-url https://download.pytorch.org/whl/cpu torch && pip install -e '.[dev]'
pytest -q
python scripts/run_probes.py --seed 0        # repeat for seeds 1, 2
python scripts/run_planning.py --seed 0
python scripts/make_tables.py
```
